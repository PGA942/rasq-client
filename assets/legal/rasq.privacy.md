### 3. 端末内に保存する情報

ネイティブ版では、SNSのログイン情報、設定、下書き、RAiの会話履歴・実績、タイムラインのカスタマイズ、ミュートした広告、発信傾向の表示に使う集計などを端末に保存します。SNSのログイン情報は、OSの安全な保存領域（iOS・macOSのKeychain、Androidの暗号化された保存領域）に保存します。

次の処理は端末の中だけで行い、その結果をRASQサーバーへ送りません：重複投稿の検出、アカウントごとの関心の推定、リアクションや並び順の予測、RAiの利用統計、端末内モデルによる分類・要約。

利用者が送信・同期を行う機能、サーバー処理を利用する機能、Web版のログイン情報保管庫では、次項以降に記載する情報が端末の外へ送られます。端末内にある情報すべてが、同じ暗号化方式・同じ保存先になるわけではありません。

端末内のデータは、アプリ内の履歴削除・ログアウト等により管理できます。アカウントの削除と、各端末のローカルデータ削除は別の操作です。OSのバックアップに含まれたデータは、そのバックアップの管理方法にも従います。

### 4. SNSの認証情報・アカウント連携

SNSのアクセストークンは、SNSでの操作を行うための認証情報です。RASQでは次の経路を区別します。

| 機能・利用条件 | 送信先と取扱い | 停止・解除 |
|---|---|---|
| 通常のSNS利用 | 選択したSNSへの投稿、閲覧、リアクション、フォロー等に必要な内容と認証情報を、端末からそのSNSへ直接送ります | SNSのログアウト・連携解除。既にSNSへ送った投稿等はSNS側で管理します |
| Mastodonの認証仲介 | RASQ個人用サーバーが、接続先のサーバーにRASQのアプリを登録し、認証コードをトークンに交換してアプリへ返します。この仲介だけを理由にトークンを保管しません | 認証の中止・SNS側での連携解除。認証処理の一時記録は1日で削除します |
| SNSログイン情報の端末間共有（任意） | 承認した端末同士で共有できるよう、端末で暗号化したログイン情報をRASQ個人用サーバーへ保存します。共有用の内容は承認端末の鍵で復号し、運営者は復号できません | 「アカウントのセキュリティ」から共有停止・端末管理。停止前に別端末へ渡ったトークンがSNS側で自動失効することはありません |
| Web版のログイン情報保管庫 | RASQアカウントへログインしてWeb版でSNSを利用すると、ログイン情報をRASQ個人用サーバーの保管庫へ送り、必要時に読み戻します。保存時はサーバーの鍵で暗号化します。運営者のサーバーが復号できる方式です | Web版のSNSログアウト、保管庫の削除、RASQアカウント削除 |
| アカウントページへのSNS投稿表示（任意） | 確認画面で同意したSNSについて、RASQ個人用サーバーがアクセストークンを受け取り、サーバーの鍵で暗号化して保存します。対象SNSから本人の表示対象投稿を取得し、RASQの公開アカウントページへ表示します。Blueskyでは、トークンではなくアカウントの識別子だけを預かり、公開の情報から取得します | 投稿表示用の預託解除、SNS連携解除、RASQアカウント削除 |
| RASQリスト・クリップの取得（任意） | 投稿表示用に預かったトークンを、RASQのリストやクリップに入れたアカウントのプロフィール・投稿の取得と、フォロー関係の確認にも使うことを別に選べます | 設定画面でこの用途を止める、預託解除 |

投稿表示用の預託は、端末間共有やWeb版保管庫とは別の選択です。この機能では、選択したSNSの「公開」および「ホーム／未収載」に相当する投稿を、**RASQのアカウントページでは誰でも見られる状態**にします。フォロワー限定、指名・DM、ローカル限定、公開範囲を確認できない投稿は対象にしません。「ホーム／未収載」はフォロワー限定という意味ではありません。

預かったトークンを、投稿・フォロー等の書き込み操作に利用しません。上の表で選んだ用途以外にも利用しません。

**アカウントの束ね表示：** 連携するSNSの種類、サーバー、アカウント識別子、表示情報、所有の確認結果を使用します。所有の確認では、RASQ公開サーバーがそのSNSの公開プロフィールを読み、確認用の文字列があるかを確かめます。Keybaseでの確認を選んだ場合は、Keybaseの公開情報も読みます。連携したSNSアカウントは、初期設定ではRASQのプロフィールに表示され、SNSのアカウントからRASQのアカウントを探せる状態になります。表示しない設定はプロフィールの編集画面で選べます。

### 6. ASTell、RAi、Swing、プラグイン、見守り、オンボーディング

**ASTell：** ルーム情報、参加情報、共有した投稿・テキスト・ファイル、文字起こし等を、選択した機能の提供に用います。音声・映像の接続先、文字起こしの送信先、参加者に見える範囲はASTellの利用条件で示します。字幕表示をオフにする操作と、文字起こし用の送信・処理を止める操作は区別します。安全管理・通報の調査のため、権限を持つ運営担当者が必要な範囲の共有内容等を確認する場合があります。

ホストが「荒らしの入室を断る」を有効にしたルームでは、入室しようとする人について、運営の判定システムが、RASQ上の自己紹介、ストアのレビュー、ASTellでの共有と文字起こし（最大200件）と画像の縮小版（最大50件）を分析し、入室の可否を決めます。利用制限を受けている人がASTellで共有する内容は、表示の前に同じシステムで確認します。判定システムが使えないときは、語の一覧による確認に切り替えます。

**RAi：** 端末内モデルの処理、回答用の推論サーバー、検索用の埋め込みサーバー、Web検索はそれぞれ別の送信経路です。外部処理を使う場合は、送信先・目的・対象データを事前に示します。質問、操作リファレンス、回答に必要な取得結果などが処理対象になることがあります。外部への送信を許可しない場合、端末内で使える範囲の機能を利用できます。端末内モデルは、Hugging Face、GitHubまたはRASQ公開サーバーからダウンロードします。ダウンロード元には、端末のIPアドレス等が伝わります。

**Swing：** 1時間から24時間で消える投稿です。投稿、画像・動画、閲覧数、だれが見たかの記録をRASQ公開サーバーに保存し、期限が来たら削除します。

**プラグイン：** プラグインが利用する情報と外部通信は、権限の説明と開発者のポリシーで確認できます。RASQ運営者が提供する機能の取扱いと、プラグイン開発者の取扱いを分けて表示します。プラグインを削除しても、既に開発者のサーバーへ送った情報が同時に消えるとは限りません。削除方法は各ポリシーに従います。

複数の利用者で同じ画面を使うプラグイン（共有セッション）では、プラグインの状態と、参加者が書き込んだ値をRASQ公開サーバーに保存し、参加者に配ります。プラグインの通信の形の診断（任意）を有効にした場合は、通信先のホスト、パス、項目名を送ります。値は送りません。

**見守り（チャイルドセーフ）：** 保護者が子どもの利用を見守る機能です。保護者の確認には、マイナンバーカードを使ったデジタル庁の本人確認を利用します。運営者が受け取るのは、18歳以上であるかどうか、居住国、確認の方法と、本人確認から作った識別子のハッシュです。カードの番号や氏名・住所は受け取りません。見守り中の子どもについて、1日ごとの利用の件数と話題の見出しを保護者へ届けます。投稿の本文は届けません。保護者が子どものアカウントを作ることもできます。

**オンボーディング（初回の案内）：** RASQアカウントの作成前でも、合いそうなSNSのサーバーや人を探す機能を使えます。この機能では、次の情報をRASQ公開サーバーへ送ります。

- 選んだ画像、アプリ内ブラウザで開いたページの本文（最大4,000文字）とURL、RAiへの相談の本文。
- 画面の読み取りを許可した場合：開始してから約3秒間の画面の画像（最大6枚）。画面の読み取りは、OSの許可の画面で開始を選んだときだけ行い、終わると止まります。

RASQ公開サーバーは、これらをクラウドのAIで分析し、人を探す場合はBrave Searchで検索します。画像と相談の本文は処理の間だけメモリに置き、保存しません。端末に残った画面の画像は送信のあとに削除します。回数の制限のために、IPアドレスを1日保存します。

### 7. 通報・安全管理・自動処理

通報や異議申立てへの対応では、対象の発信、関連する時刻・ルーム・アカウント情報、通報の前後2時間の発信、過去の対応結果を確認する場合があります。処理の補助に、文章・画像の分類、感情の8つの軸による分析、発信傾向の変化の分析、似た状況のまとめ、AIによる対応案の生成を用います。これはサービスの安全管理を目的とする推論処理であり、第10項の任意の学習用データ提供とは区別します。

この処理は、運営者が管理する判定システム（運営者の管理するコンピューター上で動作します）で行います。判定システムは、RASQ公開サーバーから必要な情報を取り出して処理し、処理の記録をそのコンピューターに保存します。保存期間は第9項に示します。AIによる対応案は、人が承認してから適用します。ただし、運営者が自動適用を有効にした場合、確度の高い一時的な制限は自動で適用することがあります。恒久的な凍結は自動では行いません。

SNSの投稿を通報した場合、その通報はSNSのサーバーの管理者へ送られます。RASQの運営者は、その通報を受け取りません。

これらの情報を扱える者を担当業務上必要な者に限定します。委託先へ処理を委ねる場合は、委託先・送信する情報・保存期間等を一覧で示します。自動処理の役割と、利用制限に対する理由の確認・異議申立ての方法は、利用規約に定めます。

### 8の2. 広告

RASQは、無料で提供する部分の費用の一部を広告でまかないます。

- **iOS・Androidのアプリ：** GoogleのAdMobを使い、タイムライン、返信、リスト、クリップ、関連タイムライン、ユーザーのページ、検索の画面、Swingの間、RAiのクラウド処理の待ち時間に広告を表示します。初回にGoogleの同意画面を表示し、パーソナライズ広告を使うかを選べます。
- **Web版と公開のWebページ：** GoogleのAdSenseを使います。AdSenseはCookieを使います。公開のWebページ（RASQのプロフィールと投稿のページ）にも広告を表示します。
- **デスクトップ版（macOS・Linux）：** Googleの広告は表示しません。接続先のSNSのサーバーが設定した広告を表示することがあります。

次の内容の前後には広告を置きません：通報された投稿、内容注意（CW）やセンシティブ指定のある投稿、審査前のプラグインの表示、運営が確認のため保留している投稿。

運営者は、DM、限定公開の投稿、ASTellの会話を広告事業者へ送りません。

### 9. 保存期間と削除

情報は目的に必要な期間に限り保存し、期間の終了または有効な削除請求により削除するか、個人を識別できない状態にします。匿名化と呼ぶ場合は、識別子を置き換えるだけの処理と区別します。

| 区分 | 保存の終期・解除方法 |
|---|---|
| 通常のアカウント・連携・同期データ | 利用中に必要な期間。個別の解除・削除またはRASQアカウント削除により削除を開始 |
| 投稿表示用トークン・取得投稿 | 預託解除またはSNS連携解除により利用停止・削除。処理中の取得・キャッシュを含む完了期限：7日 |
| Web版保管庫・端末間共有 | ログアウト・共有停止等による削除範囲を確認画面へ表示。端末間共有の承認の記録は1日、ログインの更新の履歴は30日 |
| ログインのセッション（IPアドレス・User-Agentを含む） | 最後に使ってから180日、または開始から365日で失効し、削除 |
| ログインの試行、確認コード、認証の一時処理（IPアドレスを含む） | 1日 |
| 運用ログ | 90日。リクエストの種類とパスを記録し、本文やURLの問い合わせ文字列は記録しません。ASTellと共有セッションの入退室の記録にはハンドルが含まれます |
| 通知の内容 | 30日。RASQ公開サーバーから個人用サーバーへの受け渡し待ちは最長3日 |
| ASTellの共有・文字起こし・アップロード | 参加者向け表示は作成から10日間、内部保管は作成から30日間。満了後1日以内に削除。個別の保全が必要な情報は下記の例外に従う |
| 閉じたASTellルームの記録 | 閉鎖から30日。共有・文字起こし・アップロードの期限を、ルーム閉鎖日によって延長しない |
| Swing | 投稿時に選んだ1時間から24時間。投稿に使わなかった画像・動画は1日 |
| 投稿に使わなかった画像 | 1日 |
| 共有セッションの値 | セッションの終了から30日 |
| 見守りの1日ごとの報告 | 60日。見守りの操作の記録は1年 |
| オンボーディングの回数制限に使うIPアドレス | 1日。画像と相談の本文は保存しない |
| 通報・異議申立て・対応記録（判定システムの処理記録を含む） | 対応の終結から1年。係争等で延長する場合は必要範囲・終了条件を管理。通報した人がアカウントを削除しても、対応に必要な範囲で通報を保持します |
| 契約・決済・返金・会計記録、審査料の記録 | 取引の年度の終わりから8年。アカウント削除後は、アカウントと結び付かない識別子に置き換えて保持し、ポイントの残高は0にします |
| 同意・撤回の記録 | アカウント削除から3年。同意の証明と問い合わせ対応に限って使用 |
| 削除記録・凍結回避防止情報 | 3年。後者は恒久凍結されたアカウントのハンドルと、利用を禁止した端末の識別子のハッシュに限る |
| 学習の判定の記録（第10項） | 判定から90日 |
| バックアップ | 最長35日。復元時にも削除・撤回の状態を反映 |

RASQアカウントの削除は、アプリのアカウント管理または［削除手続きURL］から行えます。アプリへ入れない場合は窓口へ連絡してください。削除時は、アカウントに結び付いた通常データの利用を停止し、削除処理を行います。学習へのデータ提供も同時に撤回し、提供済みのデータの削除を始めます。決済・返金・法令対応、係争中の権利保護、不正利用防止に必要な最小限の情報は、上表の範囲で分離して保持することがあります。

他の利用者が記録・再共有した情報、接続先SNSのアカウント・投稿、利用者の端末やバックアップは、RASQアカウントの削除だけでは消えません。RASQ側の削除処理は、各SNSのアカウントや投稿を削除する操作ではありません。

### 9の2. RASQの利用者でない方の情報

RASQの利用者がSNSで閲覧する投稿のほかに、運営者は次の場面で、RASQの利用者でない方の情報を扱うことがあります。

- 利用者がRASQのリストやクリップに入れたSNSアカウントの公開プロフィールと公開の投稿。リストの公開範囲に応じて表示します。
- 学習へのデータ提供（第10項）で、投稿の書き手が学習への利用を断っていないかを確かめるための、公開プロフィールと公開の投稿の一部。
- オンボーディングでの人探しの検索結果。

ご自身の情報の扱いについては、第11項の窓口から削除や利用停止を求められます。SNSのプロフィールで「AIの学習に使わない」旨を示している方、または検索や収集の対象外を設定している方の投稿は、学習に使いません。

### 10. 学習へのデータ提供

学習へのデータ提供は、RASQの利用とは別の任意の選択です。詳しい条件は「アルゴリズムとコミュニティへの貢献について」に示します。既定は「提供しない」で、断っても通常の機能は使えます。受付は、運営者が開始を告知するまで閉じています。

### 11. 年齢、本人の権利、変更

RASQの利用は13歳以上を対象とし、未成年者は保護者の同意を得て利用してください。これはRASQの利用条件です。年齢帯・保護者同意等の確認に必要な情報を取り扱います。追加の本人確認を行う場合は、取得する情報・事業者・保存期間を取得前に説明します。

保有する個人データの開示、訂正、利用停止・消去、第三者提供の停止等については、窓口へ請求できます。本人確認の方法、必要書類、手数料がある場合の額、対応手順は［請求手続きURL］に示します。法令に基づき対応できない場合は、その理由を説明します。

取扱いを変更する場合は、変更内容と適用日を通知します。利用目的や任意の送信範囲を拡大する場合など、改めて同意・選択が必要な変更は、変更前に確認します。過去の文書版も確認できるようにします。
