### 2. 處理資訊的目的

營運者於下列目的所必要的範圍內處理資訊。

1. 登入、身分確認、裝置管理、設定的儲存，以及提供使用者所選擇的連動、分享功能。
2. 提供貼文、通話、分享、搜尋、通知、輔助功能及外掛商店。
3. 購買、授予使用權、付款核對、退款、處理詢問，以及管理會計、法令上必要的紀錄。
4. 處理未經授權的存取、違反條款、侵害權利的情形，審查異議申訴，確保服務的安全性。
5. 保護未成年使用者，以及提供監護人的守護功能。
6. 偵測、調查故障，維持效能、品質。
7. 為支應免費提供部分的費用而顯示廣告（第8項之2）。

不會將私人對話或限定公開的貼文用於廣告的區分投放。將資訊用於模型回答、分類的處理，與將資訊累積為模型訓練資料的處理，二者有所區別。關於提供資料用於訓練，規定於第10項。

### 3. 儲存於裝置內的資訊

原生版會在裝置上儲存 SNS 的登入資訊、設定、草稿、RAi 的對話紀錄、成就、時間軸的自訂、已設為靜音的廣告、用於顯示發文傾向的統計等。SNS 的登入資訊儲存於作業系統的安全儲存區（iOS、macOS 的 Keychain、Android 的加密儲存區）。

下列處理僅在裝置內進行，其結果不會傳送至 RASQ 伺服器：重複貼文的偵測、各帳號興趣的推估、回應及排列順序的預測、RAi 的使用統計、以裝置內模型進行的分類、摘要。

在使用者進行傳送、同步的功能、使用伺服器處理的功能、網頁版的登入資訊保管庫中，下一項以後所記載的資訊會被傳送至裝置之外。裝置內的資訊並非全部採用相同的加密方式、相同的儲存位置。

裝置內的資料可透過應用程式內刪除紀錄、登出等方式管理。刪除帳號與刪除各裝置的本機資料是不同的操作。包含於作業系統備份中的資料，亦依該備份的管理方式處理。

### 4. SNS 的驗證資訊、帳號連動

SNS 的存取權杖是用於在 SNS 上進行操作的驗證資訊。RASQ 區分下列路徑。

| 功能、使用條件 | 傳送對象與處理方式 | 停止、解除 |
|---|---|---|
| 一般的 SNS 使用 | 將對所選 SNS 進行貼文、瀏覽、回應、追蹤等所需的內容與驗證資訊，從裝置直接傳送至該 SNS | SNS 的登出、解除連動。已傳送至 SNS 的貼文等由 SNS 端管理 |
| Mastodon 的驗證仲介 | RASQ 個人用伺服器在連線目標伺服器上註冊 RASQ 的應用程式，將授權碼交換為權杖後回傳給應用程式。不會僅因此仲介而保管權杖 | 中止驗證、於 SNS 端解除連動。驗證處理的暫時紀錄於1日後刪除 |
| SNS 登入資訊的跨裝置共用（選用） | 為使已核准的裝置之間能夠共用，將在裝置上加密的登入資訊儲存於 RASQ 個人用伺服器。共用內容以已核准裝置的金鑰解密，營運者無法解密 | 從「帳號安全性」停止共用、管理裝置。停止前已傳遞至其他裝置的權杖，不會在 SNS 端自動失效 |
| 網頁版的登入資訊保管庫 | 登入 RASQ 帳號並在網頁版使用 SNS 時，會將登入資訊傳送至 RASQ 個人用伺服器的保管庫，並於需要時讀回。儲存時以伺服器的金鑰加密。此為營運者的伺服器可以解密的方式 | 網頁版的 SNS 登出、刪除保管庫、刪除 RASQ 帳號 |
| 於帳號頁面顯示 SNS 貼文（選用） | 對於在確認畫面中同意的 SNS，RASQ 個人用伺服器接收存取權杖，並以伺服器的金鑰加密後儲存。從對象 SNS 取得本人應顯示的貼文，並顯示於 RASQ 的公開帳號頁面。Bluesky 不寄存權杖，僅寄存帳號的識別碼，並從公開資訊取得 | 解除貼文顯示用的寄存、解除 SNS 連動、刪除 RASQ 帳號 |
| 取得 RASQ 清單、剪輯（選用） | 可另行選擇將貼文顯示用所寄存的權杖，亦用於取得加入 RASQ 清單或剪輯之帳號的個人檔案、貼文，以及確認追蹤關係 | 在設定畫面中停止此用途、解除寄存 |

貼文顯示用的寄存，是與跨裝置共用及網頁版保管庫不同的選擇。此功能會將所選 SNS 中相當於「公開」及「首頁／不公開列出」的貼文，設為**在 RASQ 的帳號頁面上任何人皆可檢視的狀態**。僅限追蹤者、指定對象、私訊、僅限本站，以及無法確認公開範圍的貼文不在對象之內。「首頁／不公開列出」並非僅限追蹤者的意思。

寄存的權杖不會用於貼文、追蹤等寫入操作，亦不會用於上表所選用途以外的用途。

**帳號的整合顯示：** 使用所連動 SNS 的種類、伺服器、帳號識別碼、顯示資訊、所有權的確認結果。確認所有權時，RASQ 公開伺服器會讀取該 SNS 的公開個人檔案，確認其中是否含有確認用的字串。選擇以 Keybase 確認時，亦會讀取 Keybase 的公開資訊。已連動的 SNS 帳號在預設情況下會顯示於 RASQ 的個人檔案，並處於可從 SNS 帳號找到 RASQ 帳號的狀態。可在個人檔案的編輯畫面中選擇不顯示的設定。

### 6. ASTell、RAi、Swing、外掛、守護、新手引導

**ASTell：** 將聊天室資訊、參加資訊、所分享的貼文、文字、檔案、語音轉文字結果等，用於提供所選擇的功能。語音、影像的連線目標、語音轉文字的傳送對象、參加者可見的範圍，於 ASTell 的使用條件中說明。關閉字幕顯示的操作，與停止為語音轉文字而進行之傳送、處理的操作，二者有所區別。為進行安全管理、調查檢舉，具有權限的營運人員可能會在必要範圍內確認分享內容等。

在主持人啟用「拒絕搗亂者進入」的聊天室中，對於欲進入者，營運方的判定系統會分析其在 RASQ 上的自我介紹、商店的評論、在 ASTell 中的分享與語音轉文字結果（最多200則）及圖片的縮圖（最多50張），以決定是否允許進入。受到使用限制者在 ASTell 中分享的內容，會在顯示前以相同系統確認。判定系統無法使用時，改以詞彙清單進行確認。

**RAi：** 裝置內模型的處理、用於回答的推論伺服器、用於搜尋的嵌入伺服器、網路搜尋，各為不同的傳送路徑。使用外部處理時，會事先告知傳送對象、目的、對象資料。提問、操作參考、回答所需的取得結果等可能成為處理對象。不允許傳送至外部時，可使用裝置內可用範圍的功能。裝置內模型從 Hugging Face、GitHub 或 RASQ 公開伺服器下載。下載來源會得知裝置的 IP 位址等。

**Swing：** 在1小時至24小時內消失的貼文。貼文、圖片、影片、瀏覽次數、誰看過的紀錄儲存於 RASQ 公開伺服器，期限屆至時刪除。

**外掛：** 外掛所使用的資訊與外部通訊，可透過權限說明及開發者的政策確認。RASQ 營運者所提供功能的處理方式，與外掛開發者的處理方式，分開顯示。即使刪除外掛，已傳送至開發者伺服器的資訊未必會同時消失。刪除方式依各政策辦理。

在多位使用者使用同一畫面的外掛（共用工作階段）中，外掛的狀態與參加者寫入的值會儲存於 RASQ 公開伺服器，並分發給參加者。啟用外掛通訊形式的診斷（選用）時，會傳送通訊目標的主機、路徑、項目名稱，不會傳送值。

**守護（兒童安全）：** 監護人守護兒童使用情形的功能。確認監護人時，使用以個人編號卡（My Number Card）進行的日本數位廳身分確認。營運者接收的是：是否年滿18歲、居住國家、確認方式，以及由身分確認產生之識別碼的雜湊值。不會接收卡片號碼或姓名、地址。對於受守護的兒童，會將每日的使用件數與話題標題傳送給監護人，不會傳送貼文內文。監護人也可以為兒童建立帳號。

**新手引導（初次導覽）：** 即使在建立 RASQ 帳號之前，也可以使用尋找可能合適的 SNS 伺服器或人的功能。此功能會將下列資訊傳送至 RASQ 公開伺服器。

- 所選擇的圖片、以應用程式內瀏覽器開啟之頁面的內文（最多4,000字）與網址、向 RAi 諮詢的內文。
- 允許讀取畫面時：自開始起約3秒間的畫面圖片（最多6張）。僅在作業系統的權限畫面中選擇開始時才會讀取畫面，結束後即停止。

RASQ 公開伺服器以雲端 AI 分析上述資訊，尋找人時以 Brave Search 搜尋。圖片與諮詢的內文僅於處理期間置於記憶體中，不予儲存。殘留於裝置上的畫面圖片於傳送後刪除。為限制次數，會將 IP 位址儲存1日。

### 7. 檢舉、安全管理、自動處理

處理檢舉或異議申訴時，可能會確認對象發文、相關的時間、聊天室、帳號資訊、檢舉前後2小時的發文，以及過去的處理結果。為輔助處理，會使用文字、圖片的分類、以8個情緒軸進行的分析、發文傾向變化的分析、類似情況的彙整，以及由 AI 產生處理建議。此為以服務安全管理為目的的推論處理，與第10項選用的訓練用資料提供有所區別。

此處理在營運者所管理的判定系統（於營運者所管理的電腦上運作）中進行。判定系統從 RASQ 公開伺服器取出必要的資訊進行處理，並將處理紀錄儲存於該電腦。保存期間如第9項所示。由 AI 產生的處理建議，經人員核准後才會套用。但營運者啟用自動套用時，確信度高的暫時性限制可能會自動套用。永久凍結不會自動進行。

檢舉 SNS 的貼文時，該檢舉會傳送給該 SNS 伺服器的管理者。RASQ 的營運者不會接收該檢舉。

可處理上述資訊者，限於承辦業務上有必要者。委託受託者處理時，會以一覽表列示受託者、傳送的資訊、保存期間等。自動處理的角色，以及對使用限制確認理由、提出異議申訴的方式，規定於使用條款。

### 8之2. 廣告

RASQ 以廣告支應免費提供部分的部分費用。

- **iOS、Android 的應用程式：** 使用 Google 的 AdMob，在時間軸、回覆、清單、剪輯、相關時間軸、使用者頁面、搜尋畫面、Swing 之間，以及 RAi 雲端處理的等待時間顯示廣告。初次使用時會顯示 Google 的同意畫面，可選擇是否使用個人化廣告。

### 9之2. 非 RASQ 使用者的資訊

除 RASQ 使用者在 SNS 上瀏覽的貼文以外，營運者可能在下列情形中處理非 RASQ 使用者的資訊。

- 使用者加入 RASQ 清單或剪輯之 SNS 帳號的公開個人檔案與公開貼文。依清單的公開範圍顯示。
- 在提供資料用於訓練（第10項）時，為確認貼文作者是否已拒絕用於訓練而使用的公開個人檔案與部分公開貼文。
- 新手引導中尋找人的搜尋結果。

關於您本人資訊的處理，可透過第11項的窗口要求刪除或停止使用。在 SNS 個人檔案中表明「不用於 AI 訓練」之意旨者，或已設定排除於搜尋或蒐集對象之外者，其貼文不會用於訓練。

### 10. 提供資料用於訓練

提供資料用於訓練，是與使用 RASQ 分開的選用選擇。詳細條件載於「關於對演算法與社群的貢獻」。預設為「不提供」，即使拒絕仍可使用一般功能。在營運者公告開始之前，不受理申請。

### 11. 年齡、本人的權利、變更

RASQ 的使用對象為13歲以上，未成年人請取得監護人的同意後使用。此為 RASQ 的使用條件。營運者會處理確認年齡層、監護人同意等所必要的資訊。進行額外的身分確認時，會在取得前說明所取得的資訊、業者、保存期間。

關於所保有個人資料的揭露、更正、停止使用、刪除、停止提供給第三方等，可向窗口提出請求。身分確認的方式、必要文件、如有手續費時的金額、處理程序，載於［請求手續網址］。依法令無法處理時，會說明其理由。

變更處理方式時，會通知變更內容與適用日期。擴大使用目的或選用傳送範圍等需重新取得同意、選擇的變更，會在變更前確認。過去的文件版本亦可供查閱。
