各【要確定】を埋め、商品ページ・ポイント購入・注文の最終確認画面から常に参照できるようにする。

| 表示項目 | 掲載内容案 |
|---|---|
| 販売事業者 | 【正式氏名／法人名。ブランド名だけにしない】 |
| 運営責任者 | 【氏名。該当する事業形態に合わせ確定】 |
| 所在地 | 【郵便番号・住所: バーチャルオフィス（GMOオフィスサポート 梅田を予定）の住所を契約後に記入】 |
| 電話番号 | 【電話番号・受付時間】 |
| 問い合わせ | 【メールアドレス・問い合わせURL・受付時間】 |
| 販売価格 | 公開テスト期間中は、プラグイン開発者向けの審査料（申込画面に税込金額を表示）だけ。正式版では、各ポイントパックは円建て支払総額と確定した税の取扱い、各機能は必要ポイント数と税込円相当額を表示。無償分は区別 |
| 追加費用 | 通信料、利用者が別契約する外部SNS・推論サーバー等の料金。商品に不可欠なプロキシ契約は名称と料金も表示 |
| 支払方法 | 審査料・ポイント購入: Stripeで提供する【実際に採用する支払手段】。機能購入・更新（正式版）: RASQポイント |
| 支払時期 | 審査料は申込時（決済確定時）。ポイント購入は決済確定時。機能購入は利用権付与と同時、定期契約は表示した各期間開始時 |
| 提供時期 | 審査料: 申込みの受付後、申込画面に表示する目安【要確定: 30日】以内に審査に着手し結果を通知。ポイント: 決済・付与確認後【通常の所要時間】。遅延時の確認・問い合わせ方法も表示 |
| 契約期間・更新 | 商品ごとの開始日時、終了日時、周期、必要ポイント数、自動更新有無、更新停止期限・操作手順 |
| 販売数量・期間 | 申込期間、利用数・端末数・容量等に制限がある場合、その具体値 |
| 動作環境 | OS・RASQ最低版・ネット接続・対応SNS・必要な追加契約。購入前に確認可能な一覧 |
| 返品・解約・返金 | 審査料はプラグインストア・開発者条件の第4条の2（不承認だけでは返金しない、着手前の取消し・未着手・誤請求・運営者の誤りは全額返金）。ポイントと機能は上記第5条・第6条。自己都合／不具合／未提供の扱いと操作窓口を分ける |
| ポイント | 有償・無償、換算、期限、使用順、失効、退会時・制度廃止時の扱い |

住所や電話番号の省略制度を利用する場合は、利用可能な条件・請求時の遅滞ない開示・Stripeの要求事項を確認してから表示方式を決める。本案では自動的に省略しない。
