### レビュー TL(`/store/plugin/:id/reviews`)

- タブ「∨関連性 | 最新」。選択中タブの ∨ から 関連性 / 評価が高い / 評価が低い。
- タイル: アバター / 見出し + ★ + … / 投稿者 + 相対時刻 + 実利用済み・版 / 本文 / 開発者返信 /
  **アクションバー ↪️ 共有・👍 参考になった・👎 参考にならなかった** + 「N人が役に立ったと考えました。」
- 👍👎 は端末側 `ReviewVotes`(KV `store.reviewVotes.v1`)で持ち、`StoreClient.voteReview` でサーバーへ送る。
  モックは受け取って捨てる。HTTP はサーバー未実装の 404 を握って端末側の票は残す。
- + でレビュー作成シート(★ / 見出し / 本文、利用版は自動)。

### 契約の変更(`rasq-sdk-sample/openapi/store.yaml`)

- `Review`: `title` / `author {name, avatarUrl}` / `notHelpfulCount` を追加
- `PluginDetail`: `bannerUrl` / `downloadsLastMonth` / `downloadHistory` / `ratingHistogram` を追加
- `POST /reviews`: `title`
- **新規** `PUT /plugins/{id}/reviews/{reviewId}/vote` `{vote: up|down|none}`
- `GET /artifacts/{id}`: `?version=`(API.md には元からあった)

**orgate-server はこれらを未実装**。`Review` の追加フィールドは省略可なので既存応答はそのまま読める。
